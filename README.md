# 小红书 · Codex 外观 Userscript

把小红书网页版包装成类似 Codex 桌面应用的外观：左侧会话栏、中间笔记流/详情流、右侧代码装饰面板。

这是一个浏览器用户脚本，只改变当前页面的展示方式，不提供小红书官方功能的替代品。

## 功能

- 推荐流、搜索结果、用户主页和笔记详情的 Codex 风格展示
- 笔记详情正文、图片灯箱、作者和互动数据
- 评论自动分页：滚动详情页内部评论容器，并展开楼中楼；已加载评论会合并显示
- 评论接口被限流时（例如 `error_code=300013`）显示可恢复的错误页，不会把它误判成未知页面
- 保留小红书真实详情链接和 `xsec_token`
- 返回、刷新、搜索、主题、代码面板和应急伪装快捷键
- 未登录时保留原生登录流程，不读取或保存账号密码

## 安装

1. 在 Chrome、Edge 或 Firefox 安装 [Tampermonkey](https://www.tampermonkey.net/)、Violentmonkey 或同类用户脚本管理器。
2. 打开脚本管理器的“添加新脚本”页面。
3. 将 `xiaohongshu-codex.user.js` 的完整内容复制进去并保存。
4. 打开或刷新 `https://www.xiaohongshu.com/explore`。

也可以在 GitHub 的文件页面点击 `.user.js` 文件，再点击 **Raw**；已安装用户脚本管理器时通常会直接出现安装页面。

## 使用

- 点击笔记卡片进入详情。
- 详情页会自动加载原生页面允许访问的评论，并展开已出现的楼中楼。评论数量以小红书页面返回的总数为准。
- 左上角按钮分别为返回和刷新。刷新用于重新获取可能已过期的详情访问令牌。
- 左下角可以暂停/恢复伪装；设置按钮可以切换主题、面板和快捷键。
- 默认双击 `Esc` 打开应急伪装界面，也可以在设置中改成 `F2` 或 `Ctrl+Shift+H`。

## 登录与隐私

- 登录必须在小红书自己的页面中由用户完成；本脚本不会代填账号、密码或验证码。
- 脚本不会把笔记、评论或登录信息发送到第三方服务器。
- 评论加载使用小红书页面自身发起的请求；脚本只读取页面已经返回的数据，并触发详情评论区域的正常滚动/展开。
- 如果笔记因权限、登录状态、链接过期或小红书服务端限制无法打开，请先刷新推荐页，再重新进入笔记。

## 兼容性说明

- 目标站点：`https://www.xiaohongshu.com/*`
- 小红书页面结构会变化；如果站点改版导致数据无法显示，请先刷新并检查脚本管理器是否只启用了一个版本。
- 请不要同时启用旧版 `xiaohongshu-codex`，否则多个脚本实例可能互相覆盖页面。

## 开发与验证

```bash
node --check xiaohongshu-codex.user.js
```

脚本使用 `@grant none`，没有额外的跨域权限声明。
